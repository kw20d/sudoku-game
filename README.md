# Sudoku Game

A retro Sudoku game built with vanilla JavaScript and HTML Canvas, featuring randomly generated puzzles, a backtracking solver, and keyboard-based controls. It runs independently in the browser and can also plug into my [ZIX-OS terminal](https://github.com/kw20d/command-line-os) as a module.

**Play it:** [kw20d.github.io/sudoku-game](https://kw20d.github.io/sudoku-game/)

## Controls

| Key | Action |
|---|---|
| Arrow keys | Navigate the board |
| 1–9 | Enter a number in the selected cell |
| Backspace | Clear the selected cell |
| R | Restart after winning or game over |
| Esc | Stop the game (in ZIX-OS it returns you to the terminal) |

## How it works

- The board is represented as a one-dimensional array of 81 cells, with each cell storing its value and whether it is a given number.
- Puzzles are generated by creating a complete valid Sudoku solution using a randomized backtracking algorithm, then removing 50 randomly selected cells.
- The solver uses recursion and backtracking to fill empty cells while checking row, column, and 3×3 block constraints.
- Invalid entries are highlighted in red, and three incorrect attempts result in game over.
- The selected cell, its row, column, and 3×3 block are highlighted to make navigation easier.
- The game checks the board after each entry to detect when the puzzle is solved.

## Use it as a module

`sudoku.js` exports an object with three functions, allowing any page to run the game:

- `start(canvas)` generates a new puzzle and initializes the game on the provided canvas.
- `onKey(eventType, key)` handles keyboard input through the supplied event type and key.
- `stop()` provides the interface for stopping the game.

`main.js` is the standalone wrapper. It handles the canvas setup and forwards keyboard events. ZIX-OS does the same thing through its own input handler.

## Run it locally

It uses JavaScript modules, so open it through a local server:

```bash
git clone https://github.com/kw20d/sudoku-game.git
cd sudoku-game
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
